# Every runtime dependency, pinned. One file so Streamlit Community Cloud (which reads only requirements.txt) installs
# the same set the app was verified with, including the primary OCR engine (RapidOCR + onnxruntime).
# Verified together on Windows 11 / Python 3.13.5 / Tesseract 5.5.3 (see BUILD_PROGRESS.md). Linux wheels for every pin
# below exist for CPython 3.13 (checked with `pip download --platform manylinux --python-version 3.13`); the first full
# Linux install happens in the Community Cloud build (docs/DEPLOYMENT.md).
#
# OpenCV: rapidocr-onnxruntime declares `opencv-python`. The earlier two-step install used opencv-python-headless with
# `--no-deps` to avoid a second cv2 build. A single requirements file cannot say `--no-deps` for one line, so the same
# OpenCV version is pinned here under the distribution name rapidocr asks for (opencv-python==5.0.0.93, same cv2 build
# number as the headless wheel used in testing). It needs libGL, so packages.txt lists libgl1 and libglib2.0-0 (D-034).
# Tesseract itself is a native program: locally a separate install, on Community Cloud packages.txt (tesseract-ocr).
# OCR calls the tesseract executable directly (image via stdin), so no image is written to a temp file.
